# Project catalog · 101 independent projects

[简体中文](./project-catalog.md) · **English**

Each project is assigned to **exactly one primary category**; the four mini-programs are included in the 101 projects, not counted again. Category names describe discovery paths, **not production-readiness**. Most sector apps are local single-user record demos. See [screenshots](./screenshots.en.md) and [validation evidence](./project-validation-2026-10-03.md).

## How to use this catalog

1. Open a project README for its exact start command and feature boundary.
2. Run its `run.ps1` on Windows or `run.sh` on macOS/Linux; open the port above. Mini-program-only projects need the corresponding WeChat tooling for their UI.
3. Browse the [full page screenshot index](./screenshots.en.md) and [per-project validation matrix](./project-validation-2026-10-03.md).

**Safety:** Do not expose these unauthenticated local demos to the public internet or use real sensitive data. A build is not a production or device acceptance test.
