# 快速开始：先体验 3 个旗舰项目

如果你第一次打开 ai-hub，不建议从 102 个目录中随机选择。按下面顺序可以在本机快速形成完整认识。

## 1. 商城：先看完整业务链路

```powershell
./shop/run.ps1
```

打开 `http://127.0.0.1:8081`，体验商品浏览、购物车和订单流程。商城的桌面端和小程序构建都在 `shop` 目录中。

## 2. 管理后台：再看通用运营工作台

```powershell
./manage/run.ps1
```

打开分类目录中记录的管理后台端口，体验控制台、用户、角色和业务数据页面。需要 API 令牌校验时，再启动 `authcenter` 并按[鉴权接入说明](./auth-integration.md)配置。

## 3. 安全与身份中心：最后看共性底座

```powershell
./authcenter/run.ps1
```

打开 `http://127.0.0.1:8182`，使用 README 中的演示账号查看令牌签发、公钥发现和审计试点。它是本机演示，不是生产身份平台。

## 常见问题

- **端口冲突：**每个项目使用独立端口，以对应 README 和分类目录为准；先停止占用端口的进程。
- **前端依赖失败：**确认 Node.js 20.19+/22.12+，删除项目内 `node_modules` 后重新执行 `npm ci`。
- **页面没有更新：**先执行前端构建，再启动后端；不要直接把开发目录当成 jar 内静态页面。
- **想部署公网：**不要直接暴露本仓库示例服务。先完成鉴权、权限、密钥、数据持久化、备份、限流、日志和安全评审。
