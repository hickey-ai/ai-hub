# 快速开始：本机体验 3 个代表项目

从**仓库根目录**执行下方命令。准备 Java 21、Maven、Node.js 20.19+/22.12+ 和 npm；首次运行会联网下载依赖、构建 Vue 页面、执行后端测试并打包。每个启动命令会占用当前终端，看到服务启动完成后再打开浏览器；按 `Ctrl+C` 停止。三个项目相互独立，先选一个体验即可。

| 项目 | Windows PowerShell | macOS / Linux | 本机页面 |
| :--- | :--- | :--- | :--- |
| 商城 | `./shop/run.ps1` | `./shop/run.sh` | `http://127.0.0.1:8081` |
| 管理后台 | `./manage/run.ps1` | `./manage/run.sh` | `http://127.0.0.1:8082` |
| 安全与身份中心 | `./authcenter/run.ps1` | `./authcenter/run.sh` | `http://127.0.0.1:8182` |

## 1. 商城：商品到演示订单

启动商城后打开 `http://127.0.0.1:8081`：

1. 在商品区域按类目筛选或搜索，打开一个商品查看详情、价格和库存。
2. 加入购物车，调整数量，进入结算并填写**虚构的**称呼和邮箱。
3. 提交后页面显示演示订单号；不会发生真实支付或配送。订单和库存写入本地 `shop/data/shop.json`，重复体验会改变库存。

需要恢复初始商品数据时，先停服，备份或删除 `shop/data/shop.json`，再启动商城；**不要在服务运行时删文件**。小程序需额外执行 `./shop/run-miniprogram.ps1` 或 `./shop/run-miniprogram.sh`，然后用微信开发者工具导入 `shop/miniprogram/dist/build/mp-weixin/`；本机浏览器截图不是微信真机验收。配置 AppID、合法 HTTPS 域名及真机调试要求见[商城说明](../shop/README.md)。

## 2. 管理后台：列表与记录

启动管理后台后打开 `http://127.0.0.1:8082`；默认是**仅本机免登录演示**：

1. 在控制台查看指标，进入“用户管理”搜索和筛选演示成员。
2. 点击“添加用户”，用虚构资料保存一条记录；列表随之更新。
3. 打开“操作日志”查看本次变更。用户和新增操作记录保存在 `manage/data/manage.json`，重启后仍在；需要恢复默认数据时，停服后备份或删除该文件。

默认模式不提供真实身份验证，角色与菜单也不是权限控制。**若配置 `AIHUB_AUTH_ISSUER_URI`，管理后台的 `/api/**` 会要求 JWT，但浏览器还没有单点登录流程，页面无法像默认模式一样完成上述操作。**令牌联调请按[鉴权接入说明](./auth-integration.md)使用 API 客户端，不要误认为只加配置就得到完整后台登录。

## 3. 安全与身份中心：本机令牌试点

单独启动安全与身份中心，打开 `http://127.0.0.1:8182`：

1. 用演示账号 `admin / admin123` 登录，查看会话状态与管理员审计视图；`operator / operator123` 不能查看管理员审计。
2. 查看发现文档和公钥端点，再在界面清除会话。清除浏览器令牌**不会撤销**此前签发的 JWT。

账号、RSA 密钥和审计记录仅用于本机演示；重启后旧令牌失效。若要同时连接管理后台 API，需要在**另一个终端**启动管理后台，并在启动前设置兼容的签发者与受众。具体命令、401/200 验证和限制见[鉴权接入说明](./auth-integration.md)及[安全中心说明](../authcenter/README.md)。**不要把演示账号、令牌或业务数据用于公网环境。**
