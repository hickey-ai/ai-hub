# 国家战略软件建设设计：先交付可验证的能力

**[中文](./strategic-software-design.md) · [English](./strategic-software-design.en.md)**  
2026-10-06 · 对照[国家战略软件缺口](./strategic-software-gap.md)。本设计是 ai-hub 的工程计划，不是政策认证或全部战略软件已交付的声明。

## 目标与分层

```text
浏览器 / 小程序（业务入口）
       │ 请求与身份
       ▼
业务应用 API ── 授权与审计（下一阶段）
       │
       ├── 制造工单 ── 状态机 ── 离线设备模拟器 ── 事件追溯（本次已实现）
       ├── 测试执行 ── 隔离运行器 / 报告（待实现）
       └── 人工智能 ── 可选模型网关 / 评测（待实现）
       │
       ▼
各应用本机 JSON（演示；没有事务数据库、跨服务平台或防篡改能力）
```

**首个增量**复用现有 [manufacturing](../manufacturing/README.md) 目录，不增加空项目：`POST /api/workorders/{id}/simulate` 接受由客户端生成的唯一事件编号、事件类型和产量；服务端在同一同步临界区校验状态和计划产量、追加事件、原子替换本机数据文件。`GET /api/workorders/{id}/trace` 返回工单状态、累计产出、事件。事件编号重试返回既有事件；相同编号对应不同内容返回 409；异常停机禁止产出；已有事件的工单不能被普通编辑任意改变状态或删除。旧数据文件不含事件字段时作为空事件加载。

**不能用作真实生产**：模拟器不采集设备信号、不控制设备、不防止用户直接修改本机 JSON；无身份验证、消息队列、签名、时间同步或工业网络隔离。设备在环、断网缓冲、外部协议安全、并发多用户、数据库迁移与灾备均未验收。截图仅为本机运行界面。[实际页面](../manufacturing/screenshots/simulator.png)与[项目 API/运行说明](../manufacturing/README.md)。

## 后续批次与验收门槛

| 顺序 | 具体交付，不以目录数量计数 | 自动化/人工验收 |
| :--- | :--- | :--- |
| P0 安全底座 | 选一个现有业务项目接入可配置签发者，完成浏览器登录、服务端资源级授权与审计，再抽取可复用模块 | 无令牌 401、越权 403、过期/轮换、敏感日志脱敏；两角色真实浏览器操作；其余项目仍单独盘点 |
| P1 制造流程增强 | 设备协议适配器与离线队列、事件签名、断线重传、异常处置与追溯导出；避免直接连接工业控制网络 | 模拟设备重启/重复/乱序/断线测试、产量守恒；真实设备与现场安全需另行授权验收 |
| P1 开发测试工具 | 测试管理增加独立隔离执行器，禁止任意命令；保存版本、用例、日志和结果 | 白名单、超时、资源限额、失败回放、恶意输入拒绝、恢复测试 |
| P2 工业设计和经营 | 选定一项可复算仿真模型；采购/库存/结算实现事务闭环 | 与已知样本比对；重复请求、并发扣减、回滚及权限用例 |
| P2 人工智能软件 | 可选本机/外部模型网关，不内置密钥和默认数据上传 | 限额、超时、失败降级、敏感数据保护、提示注入样例与人工复核 |
| 独立立项 | 操作系统、数据库、编译器、中间件、云平台、设备固件 | 需领域专家、专门技术栈、性能与安全基准；不能靠新增 Vue/Java 页面宣称完成 |

**本次验证**：制造项目 Maven 测试包含非法输入、状态冲突、事件幂等、超量、停机、恢复、质检、不可绕过编辑/删除、重启后持久性；前端构建及本机浏览器模拟操作另行核对。测试范围不等于真实设备或 101 项全量业务验收；可复跑 `mvn -f manufacturing/backend/pom.xml test` 与 `npm --prefix manufacturing/frontend run build`。
